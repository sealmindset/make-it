# /resolve-it pattern library (shipped seeds)

Generic root causes, one per file, in the format of `references/resolve-it.md` §10. `/resolve-it`
Phase 3 matches their `signals` against the evidence before theorizing; a match is a hypothesis to
prove, never a conclusion. The owner's learned patterns live in `~/.claude/resolve-it/patterns/`
(user-level, never overwritten by an install); propose one here as a PR when it is worth shipping.
No project, firm, client or account names in any pattern.
